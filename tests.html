Phat Gym Track - test harness

Pure-function regression suite for WO-001 (B-01 / B-02 / B-03 / B-21) and WO-003 (the advice batch). Open this file directly from file://. No server, no Node, no network, no framework. Every test is named after the backlog ID and the work-order acceptance criterion it covers.
Target shape is N / N / 0. No expected failure is carried forward. A failure kept alive as "the known one" becomes a rule applied from memory, and that is how a second, real failure gets waved through (WO-003 §Decision 1). Two meta-tests at the end enforce it: one fails on any test NAME that labels itself a carried-forward failure, one fails on a skip with no stated reason.
Coverage. S0-S15 are WO-001 plus W1's ordering and training-week counting. S16-S17 are the verdict seam and the P1/H1/Z1-Z3/G1/I2 rules. S18-S24 are the five advice engines (W7 Rule W1 calories, W9 Rule ST1 stalls, W12 Rule SP1 speed load, W14 Rule V1 volume tier, W19 Rule D1 deload) together with the docs/coach-audit-addendum.md §7 rulings: E1 (an abandoned date breaks a failure streak), E2 (a deload date is not evidence), DL1 (a deload week never recommends more weight) and N3 (a short previous entry is not a first session).
