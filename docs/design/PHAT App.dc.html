What it does

Steppers move weight by your chosen increment and reps by one. Entering reps auto-starts the countdown from the prescribed rest. Finishing an exercise's last set prints the overload verdict inline. + Add set appends beyond the prescription and marks it extra; volume counts it, the prescription doesn't change.

The Plan tab treats PHAT as a duplicable template: rename it, reorder days, rename or delete exercises, change set counts, add days, or start from empty. Settings holds the weeks 1–4 volume toggle and switches between sample data and an empty log.

Still open

Movement illustrations are labelled placeholders — supply real ones and they drop in. Charting is deliberately four sparklines rather than one multi-lift chart; say the word if you want the combined view. And the honest caveat from the brief still stands: this is the fourth tool built for a programme with sessions still to log.
